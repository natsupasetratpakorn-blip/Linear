# BuiltByBit page

- `00-banner.png` is the resource banner (1920×960).
- `01` to `12` are the description, top to bottom. Upload them in order and paste
  `description.bbcode`, replacing each `UPLOAD ...` with the uploaded image link.

All in-game pictures are real screenshots from a Minecraft 1.21.11 client on Paper 1.21.11.
Benchmark numbers are the ones in the main README.
